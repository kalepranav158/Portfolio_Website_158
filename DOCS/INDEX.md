## Documentation Standards
Every sprint document (`SPRINT_XX_*.md`) must record:
1. **Sprint Objectives & Scope**: Targeted phases and user stories.
2. **Architecture & Design Decisions**: Rationale for technical choices.
3. **Artifacts & Files Created / Modified**: Exact paths.
4. **Validation & Test Execution**: Exact commands executed and their output.
5. **Issues & Mitigations**: How blockers or edge cases were handled.
6. **Next Sprint Handoff**: Prerequisites for subsequent phases.
